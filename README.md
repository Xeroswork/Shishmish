# 🔥 Shish-Mish — сайт

Одностраничный статичный сайт заведения в Софии: шашлык и дюнер на углях из фермерских продуктов.
Заказ оформляется через мессенджеры: посетитель собирает корзину, а сайт формирует готовый текст заказа
для **WhatsApp** (подставляется в чат автоматически) или копирует его в буфер для **Viber**.

- Три языка: **BG** (по умолчанию), **EN**, **RU**. Выбор запоминается в браузере.
- Без сборки и зависимостей: HTML + CSS + обычные скрипты с `defer`. Работает drag & drop на любом хостинге
  и просто при открытии `index.html` двойным кликом.
- Корзина сохраняется в `localStorage` и переживает перезагрузку и смену языка.

## Как добавить блюдо

1. **Запись в меню** — в `js/menu-data.js` добавьте объект в массив `MENU` (порядок в массиве = порядок на сайте):

   ```js
   {
     id: 'lulya',                       // латиницей, без пробелов, уникальный
     category: 'grill',                 // 'grill' или 'drinks'
     price: 10,                         // цена в евро: 10, 6.5 …
     weight: { value: 350, unit: 'g' }, // 'g' → «350 г», 'pc' → «1 бр.» (только для блюд)
     nameKey: 'dish_lulya_name',
     descKey: 'dish_lulya_desc',
     image: null,                       // пока нет фото — будет красивый плейсхолдер
     widths: [400, 800, 1200],
   },
   ```

   Для напитков-брендов вместо `nameKey` можно написать `name: 'Schweppes'` — название не переводится.

2. **Переводы** — в `js/i18n.js` в **каждый** из трёх словарей (`bg`, `en`, `ru`) добавьте ключи:

   ```js
   dish_lulya_name: 'Люля кебап',
   dish_lulya_desc: 'Сочно кайма на въглища.',
   ```

   Если забыть перевод, на сайте появится болгарский текст (или сам ключ, если его нет и в `bg`).

3. **Структурированные данные (по желанию)** — чтобы блюдо попало в карточку Google, добавьте его в блок
   `application/ld+json` в `<head>` файла `index.html` (раздел `hasMenuItem`).

Карточка, кнопка «Добавить», корзина и текст заказа для мессенджеров подхватят новую позицию автоматически.

## Как добавить или заменить фото

Нужен Python 3 и Pillow 11+ (`pip3 install pillow`).

1. Положите оригинал (PNG или JPG, лучше с прозрачным или чёрным фоном, от 1200 px) в
   `assets/images/src/` — имя файла без пробелов, например `chicken.png`.
2. Из корня проекта запустите:

   ```bash
   python3 tools/optimize_images.py chicken
   ```

   Скрипт создаст `assets/images/chicken-400.avif`, `…-800.webp` и т. д. и напечатает строку с размерами.
3. В `js/menu-data.js` замените у блюда `image: null` на напечатанное значение, например
   `image: { name: 'chicken', width: 2000, height: 2000 }`.

Без аргументов скрипт пересобирает все картинки. Ширины для особых картинок (hero, напитки) задаются
в словаре `PROFILES` в самом скрипте; остальные фото получают 400 / 800 / 1200 px. У иллюстраций блока
«Как готовим» (`TRIM`) скрипт сам обрезает пустые прозрачные поля, чтобы в кружках они были одного масштаба.

## Как поменять телефон

1. `js/menu-data.js` — константы `PHONE` (цифры без «+», для WhatsApp/Viber/звонка) и `PHONE_DISPLAY`
   (как номер показывается). Тексты FAQ подставляют номер автоматически.
2. `index.html` — номер прописан в ссылках (`tel:+…`, `wa.me/…`, `viber://…`) и в видимом тексте.
   Найдите и замените `359888245737` и `+359 888 245 737` по всему файлу.
3. `index.html` — поле `"telephone"` в блоке `application/ld+json`.

## Как поменять тексты

Все тексты — в `js/i18n.js`, по одному словарю на язык. Ключи одинаковые во всех трёх словарях.
В строках можно использовать `<em>…</em>` (огненный акцент в заголовках) и `{phone}` (подставится номер).

## Шрифты

Уже лежат в `assets/fonts/`, скачивать ничего не нужно:

- **Unbounded** (заголовки) и **Inter** (текст) — лицензия SIL Open Font License;
- вариативные WOFF2: один файл покрывает все начертания;
- для каждого шрифта два сабсета — **кириллица** (нужна для BG и RU) и **латиница** (EN, цифры, €).

Если когда-нибудь понадобится обновить шрифты — берите в Google Fonts **и** `cyrillic`, **и** `latin`
сабсеты. Одних латинских файлов для болгарского и русского недостаточно.

Шрифты подключены с `font-display: optional` и предзагружаются в `<head>` раньше стилей: к первой
отрисовке они уже есть, и текст никогда не «прыгает» при подмене шрифта. Для резервных шрифтов
(`Unbounded Fallback`, `Inter Fallback` в начале `style.css`) подобраны `size-adjust` и метрики так, что
заголовок первого экрана занимает столько же строк, сколько с настоящим шрифтом. Если поменяете шрифт
заголовков или текст заголовка hero — эти коэффициенты стоит перепроверить.

## Деплой

Сборка не нужна — выкладывается папка как есть. Папки `tools/` и `assets/images/src/` (оригиналы фото,
~34 МБ) на сайт выкладывать не обязательно — они нужны только для пересборки картинок.

- **Netlify** — перетащите папку на app.netlify.com/drop. Файл `_headers` включит долгий кэш для шрифтов и картинок.
- **Vercel** — `vercel deploy` из папки проекта или импорт репозитория; фреймворк: *Other*, команда сборки не нужна.
- **GitHub Pages** — загрузите файлы в репозиторий → Settings → Pages → Source: `main`, `/ (root)`.

После покупки домена замените `https://example.com` в `index.html` (`og:url`, `og:image`),
`robots.txt` и `sitemap.xml`, и добавьте `<link rel="canonical">` (см. комментарий `TODO(owner)` в `<head>`).

## Проверить локально

Можно просто открыть `index.html` двойным кликом — всё работает (меню, корзина, языки).
Чтобы увидеть сайт ровно как на хостинге (с манифестом и предзагрузкой шрифтов без предупреждений
в консоли), запустите локальный сервер:

```bash
python3 -m http.server 8752
```

и откройте http://localhost:8752.
